# The Wellington Diner

Diner-mode preview of [wellingtondiner.com](https://www.wellingtondiner.com/).

Tables by phone: **(613) 798-7800**. No fake booker.

The booth host answers menu, hours, and how to book from the printed board. It cannot hold a table. Optional `XAI_API_KEY` makes replies a bit more conversational; without it, the host still uses the board.

```bash
npm install
npm run dev -- --port 3610
```
